PC 등록 방법

PC 등록은 각 Windows PC에 설치된 에이전트 프로그램이 자동으로 수행합니다.

  1. 에이전트 프로그램 실행 시 등록 승인 창이 표시됩니다
  2. "예"를 선택하면 등록 요청이 서버로 전송됩니다
  3. 대시보드에서 등록 요청을 확인하고 승인하세요
